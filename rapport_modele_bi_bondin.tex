\section*{\textcolor{fidnessblue}{1. Contexte du Projet \& Périmètre d'Analyse}}
Ce document consacre la phase de \textbf{cadrage et de réalisation du Data Warehouse (DWH)} pour le pilotage décisionnel de l'application de fidélité mobile \textbf{« Ena w Bondin »}, fruit du partenariat stratégique entre les Cafés \textbf{BONDIN} et l'éditeur de fidélité digitale \textbf{FIDNESS}.

Les données sources proviennent d'une extraction de production PostgreSQL multi-enseignes. Le pipeline ETL Python développé a permis d'isoler l'enseigne Bondin (\texttt{company\_id = 2}), de pseudonymiser les identités clientes (norme RGPD / RLS), de convertir les montants exprimés en millimes vers les Dinars Tunisiens (TND) et de générer un modèle décisionnel optimisé en \textbf{Schéma en Étoile (Star Schema)} prêt pour Power BI.

\vspace{0.2cm}
